zDPlayerLocation

versión 1.0.0 — por Donatier

Un plugin chico pensado para una sola cosa: mostrar de qué país es cada jugador, con la etiqueta, el color y el estilo que vos quieras para cada uno — sin mostrarle la IP a nadie, solo el resultado.

Spigot Paper Purpur Folia 1.16+ PlaceholderAPI (opcional)

Introducción

Al entrar un jugador, el plugin resuelve su país a partir de su IP y arma una etiqueta como [VNZ] o [MX] — la ponés en el tab, en el mensaje de bienvenida, o la usás como placeholder en cualquier otro plugin. Los 199 países vienen todos listados en config.yml para que edites cada uno a tu gusto: la etiqueta, el color, y si va en negrita, cursiva o subrayado.

Instalación

  1. Descarga zDPlayerLocation-1.0.0.jar.
  2. Colócalo en /plugins.
  3. Reinicia el servidor. Se genera config.yml y cache.yml dentro de /plugins/zDPlayerLocation.
  4. Editá los países que quieras y usá /zdpl reload.

Privacidad

Para saber de qué país es alguien, el plugin le manda su IP a un servicio externo gratuito de geolocalización (ip-api.com por defecto, configurable en geolocation.api-url). No manda ningún otro dato del jugador, y lo que guarda es solo el código de país — nunca la IP en sí. Si tu jugador se conecta desde una red local (127.0.0.1, LAN), el plugin lo detecta solo y no hace ninguna consulta externa, usando directamente la etiqueta local.

El país se vuelve a consultar en cada conexión, nunca se queda pegado a uno viejo — si un jugador cambia de red o de país entre una sesión y otra, se nota apenas se vuelve a conectar.

Países (nombre / tag / degradado / estilo)

Cada país tiene su propio bloque, completamente editable:

countries:
  VE: # Venezuela
    name: "Venezuela"
    tag: "VNZ"
    gradient: ["#F9EF80", "#6BD1FA", "#E65151"]
    small-caps: true
    bold: true
    italic: false
    underline: false

gradient es una lista de 1 o más colores hexadecimal: con uno solo queda liso, con dos o más el plugin interpola el color letra por letra, de punta a punta del tag — así es como sale el efecto de VNZ con cada letra de un color distinto. small-caps convierte el tag a versalitas (mayúsculas pequeñas, como ᴠɴᴢ) automáticamente; no hace falta escribirlas así vos mismo, solo escribí "VNZ" normal. name es el nombre completo del país, sin color ni estilo — para cuando querés mostrarlo "normal" en vez del tag.

default se usa para cualquier país que no esté en la lista o cuando falla la consulta; local es la que se le pone a alguien conectado desde una red local.

Los 199 países están cargados de fábrica, todos con nombre en español, tag y degradado. Le puse colores de bandera reales a los más pedidos (toda Latinoamérica, España, Estados Unidos, Alemania, Francia, Italia, Reino Unido, Rusia, China, Japón, India, Canadá...). Al resto le tocó un degradado genérico de 2 tonos para que no quedaran todos lisos — si querés que algún país en particular tenga los colores reales de su bandera, decime cuál y se lo cambio.

Tab, bienvenida y despedida

display:
  format: "&8&0((%tag%&8&0))"
  tab-suffix-enabled: true
  join-message-enabled: true
  join-message: "&a+ &7%player% &7se conectó desde &8&0((%tag%&8&0))"
  leave-message-enabled: false
  leave-message: "&c- &7%player% &7se desconectó."

%tag% ya viene coloreado y con el estilo de ese país aplicado; %name% es el nombre del país en texto plano, sin color, para cuando preferís mostrar "Venezuela" en vez de "((VNZ))". tab-suffix-enabled agrega el resultado al final del nombre en la lista de jugadores (tab). El mensaje de bienvenida y el de despedida se activan y redactan por separado.

Respaldo si falla la consulta

El país se resuelve de nuevo cada vez que alguien se conecta - nunca se usa un resultado viejo como atajo. cache.yml solo entra en juego como respaldo: si en un momento dado la consulta a internet falla (sin conexión, servicio caído), el plugin usa el último país que sí pudo resolver para ese jugador, mientras no sea más viejo que geolocation.cache-hours horas. 

geolocation:
  cache-hours: 720
  local-ip-country-code: "LOCAL"

Placeholders

Si tenés PlaceholderAPI instalado, quedan disponibles automáticamente:

PlaceholderMuestra
%zdplayerlocation_country%El resultado completo ya formateado, ej. ((VNZ)) con su degradado.
%zdplayerlocation_tag%Solo el tag con su degradado y estilo, sin los paréntesis del formato, ej. VNZ coloreado.
%zdplayerlocation_name%Nombre completo del país en español, sin color, ej. Venezuela.
%zdplayerlocation_code%Código ISO crudo devuelto por la consulta, ej. VE.

Podés usarlas en el chat de otro plugin, en el tab de otro plugin de tablist, en un menú, donde quieras que acepte placeholders de PlaceholderAPI.

Permisos

PermisoFunción
zdplayerlocation.*Otorga todos los permisos.
zdplayerlocation.reloadPermite recargar la configuración.
zdplayerlocation.lookupPermite consultar tu propio país.
zdplayerlocation.lookup.othersPermite consultar el país de otros jugadores.
zdplayerlocation.see-tagReservado para futuras opciones de visibilidad por jugador.

Compatibilidad

Compilado contra la API de Spigot (no la de Paper), así que corre igual en Spigot, Paper, Purpur o Folia desde la 1.16 en adelante, sin usar ninguna función exclusiva de Paper. Si tenés PlaceholderAPI instalado, el plugin lo detecta solo al arrancar y registra sus placeholders; si no lo tenés, simplemente no hace nada raro, el resto del plugin funciona igual.

Para desarrolladores: compilar desde el código fuente

Si en vez del .jar descargaste el código fuente:

cd zDPlayerLocation
mvn clean package

El archivo final queda en target/zDPlayerLocation-1.0.0.jar.

Requiere Java 17+ y conexión a internet la primera vez, para que Maven descargue las dependencias.
